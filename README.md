# OmniBrain


Agentic Multi-Modal RAG Orchestrator using LangGraph, FastAPI, Qdrant, Vision-Language Models

## 🏗️ Project Architecture

OmniBrain is an agentic multi-modal Retrieval-Augmented Generation (RAG) system designed to process and analyze documents using modern AI technologies.

## 💻 Tech Stack

- **Frontend:** Streamlit
- **Backend:** FastAPI
- **Orchestration:** LangGraph
- **Vector Database:** Qdrant
- **Language Models:** Vision-Language Models (VLMs)
- **Programming Language:** Python
