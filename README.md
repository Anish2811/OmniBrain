# OmniBrain

Agentic Multi-Modal RAG Orchestrator using LangGraph, FastAPI, Qdrant, Vision-Language Models.

## Project Overview

OmniBrain is an AI-powered multi-modal RAG (Retrieval-Augmented Generation) system designed to process and understand different types of data, including text, images, charts, and financial reports.

## Tech Stack

- Frontend: Streamlit
- Backend: FastAPI
- AI Orchestration: LangGraph
- Vector Database: Qdrant
- Vision Model: Vision-Language Models (VLM)
